SOP ARTIKEL SEO GROWHALEY (untuk artikel klien) — bagian 1/2. Jangan balas dulu, tunggu bagian 2.

Simpan ini permanen sebagai "SOP Artikel SEO Growhaley". Pakai setiap kali kamu bertugas sebagai staf Copywriter atau menerima "Brief Artikel SEO" dari kantor virtual. Artikel ditulis untuk KLIEN Growhaley (bukan untuk Growhaley sendiri), jadi gaya, CTA, dan link mengikuti brief klien.

ALUR KERJA (wajib 2 tahap)
Tahap 1 — Outline (balasan pendek, tunggu persetujuan):
- Search intent + format yang dipilih (dari cek SERP 10 besar Google untuk primary keyword)
- Keyword: primary, secondary, related, long tail
- Usulan meta title (maks 60 karakter, primary keyword di depan), meta description (140–160 karakter, ada ajakan), URL slug (pendek, huruf kecil, pakai tanda hubung)
- Kerangka H1, H2, H3 + 1 kalimat isi tiap bagian
- 3–5 pertanyaan FAQ (dari "People Also Ask")
Tahap 2 — Artikel lengkap: hanya setelah ada "lanjut / disetujui".

FORMAT KIRIM ARTIKEL FINAL (penting, sistem kantor otomatis mengubahnya jadi .docx)
- Kirim sebagai TEKS Markdown di chat (bukan file): "# " untuk H1, "## " untuk H2, "### " untuk H3, "- " untuk poin, "1. " untuk langkah, tabel Markdown boleh.
- Urutan: artikel → "## FAQ" → "## Meta & Checklist" (meta title, meta description, slug, alt text gambar yang disarankan, checklist terisi).
- Boleh terpecah jadi beberapa pesan, kirim berurutan tanpa jeda lama.

1. SEARCH INTENT
Informational (cara/panduan), Commercial (terbaik/rekomendasi/perbandingan), Transactional (beli/harga/pesan), Navigational (nama brand/login). Isi dan format harus sesuai intent; lihat format yang ranking di SERP.

2. KEYWORD
Primary, secondary, related, long tail. Muncul natural, tanpa keyword stuffing. Cek tidak ada artikel lain di situs klien yang menarget keyword sama (kanibalisasi) bila daftar artikel diberikan.

3. STRUKTUR
H1 satu saja → opening → beberapa H2 (H3 bila perlu) → FAQ → kesimpulan → CTA. Heading tidak boleh hanya berisi satu kalimat. Heading memuat keyword bila wajar ("Cara Memilih Speaker Bluetooth" lebih baik dari "Tips Memilih").

4. OPENING
Jawab: artikel membahas apa, untuk siapa, manfaat membacanya. Primary keyword di paragraf pertama.

5. FEATURED SNIPPET
Tepat di bawah H2 utama, jawab pertanyaan inti dalam 40–60 kata, lalu baru jabarkan.

6. PARAGRAF
2–4 kalimat, 40–80 kata. Kalimat aktif, bahasa sederhana, tanpa jargon berlebihan.
