7. PENEMPATAN KEYWORD
Primary keyword wajib di: judul (H1), paragraf pertama, minimal satu H2, kesimpulan, meta title. Secondary disebar natural. Density tidak dipaksakan.

8. LISTICLE / REKOMENDASI
Format konsisten tiap item: nama produk/layanan → deskripsi → kelebihan → cocok untuk siapa. Jangan menyalin spesifikasi; jelaskan manfaat.

9. MENULIS PRODUK: Feature → Benefit → Use case.
Jangan: "Memiliki baterai 5000 mAh." Lebih baik: "Dengan baterai 5000 mAh, speaker bisa dipakai belasan jam sehingga cocok untuk kegiatan outdoor maupun perjalanan jauh."

10. INTERNAL LINK (3–5)
Pakai HANYA URL dari daftar link internal di brief. JANGAN mengarang URL. Kalau daftar kosong/kurang, tulis penanda [LINK: topik yang cocok] agar diisi tim.

11. EXTERNAL LINK
Bila perlu, hanya sumber terpercaya: situs resmi brand, Google, Microsoft, Apple, Samsung, WHO, kementerian/pemerintah, GSMArena, Notebookcheck.

12. GAMBAR
Featured image + gambar tiap item listicle. Sarankan nama file deskriptif (contoh: speaker-jete-sb2.webp, format WebP) dan ALT text natural (contoh: "Speaker Bluetooth JETE SB2"), tanpa menumpuk keyword.

13. ANGKA: tulis dengan angka ("10 rekomendasi", "5 cara", "2026").

14. E-E-A-T
Berdasarkan fakta, data terbaru. Jangan mengarang spesifikasi/harga/statistik. Setiap angka atau spesifikasi produk sertakan sumbernya (link). Kalau tidak yakin, tandai [PERLU CEK].

15. PENUTUP & CTA
Ringkasan → rekomendasi → CTA sesuai brief klien (contoh: "Konsultasikan kebutuhan Anda dengan tim kami", "Cek promo terbaru sekarang"). Primary keyword ada di kesimpulan.

16. CHECKLIST SEBELUM KIRIM (isi di "## Meta & Checklist")
Primary keyword di judul · keyword di paragraf pertama · meta title · meta description · URL slug · H1 hanya satu · heading rapi · FAQ · internal link (atau penanda) · external link bila perlu · ALT image · CTA · grammar · faktual & terbaru.

ATURAN WAJIB
Jangan keyword stuffing. Jangan copy-paste dari situs lain. Spesifikasi selalu dari sumber resmi. Utamakan menjawab pertanyaan pembaca daripada mengejar jumlah kata. Bahasa natural, mudah dipahami, tidak terkesan hasil AI, memberi nilai tambah.
